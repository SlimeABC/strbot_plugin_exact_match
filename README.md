# 精确匹配回复插件
astrbot_plugin_exact_match

**AstrBot 精确匹配自动回复插件，支持自定义关键词与回复内容的一对一完全匹配**

### 功能
- 完全匹配触发，避免 substring 误触（如配置"你好"，不会对"你好啊"进行响应）
- 支持多组关键词-回复规则并行配置
- 正确处理@机器人的消息场景


### 配置

- **触发词列表** - 触发回复的关键词，每行一个（默认 `["你好", "帮助"]`）
- **回复内容列表** - 对应触发词的回复，每行一个（默认 `["你好呀！", "这是精确匹配插件"]`）

**注意**：两行列表顺序必须一一对应，第一行触发词对应第一行回复，以此类推。

使用示例

配置：
- 触发词：`["test", "help"]`
- 回复：`["pass", "help document\nv1.0\nthis is a bot"]`

对话：
```
用户：test
机器人：pass

用户：help
机器人：help document
v1.0
this is a bot

用户：Test
机器人：调用LLM或无响应

用户：help me!!!
机器人：调用LLM或无响应
```
